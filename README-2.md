# CodeAlpha Language Learning App

A clean Python Tkinter + SQLite language learning application created for CodeAlpha App Development Task 4.

## Features
- English to Afaan Oromo vocabulary and phrases
- Translations and pronunciation
- Flashcards with Show Answer
- Next and Previous navigation
- Add, edit and delete learning items
- Multiple-choice practice quiz
- Progress dashboard
- SQLite local database
- Clean Tkinter user interface

## Requirements
- Python 3.9 or newer
- Tkinter (normally included with Python)
- SQLite3 (included with Python)

No external Python packages are required.

## Run
```bash
python main.py
```

The file `language_learning.db` is created automatically the first time the application runs.
