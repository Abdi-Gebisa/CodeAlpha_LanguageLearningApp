# CodeAlpha Language Learning App

A simple Language Learning App developed using Python Tkinter and SQLite for the CodeAlpha App Development Internship.

## Features

- English to Afaan Oromo vocabulary
- Afaan Oromo translations
- Pronunciation guide
- Flashcards
- Next and Previous buttons
- Add, edit, and delete learning items
- Multiple-choice quizzes
- Learning progress tracking
- SQLite local database
- Clean and user-friendly interface

## Technologies

- Python
- Tkinter
- SQLite

## How to Run

Run the following command:

python main.py

The database is created automatically when the application starts.

## Project

This project was developed as:

**CodeAlpha App Development — Task 4: Language Learning App**

The application helps users learn new words and phrases through translations, pronunciation, flashcards, quizzes, and progress tracking.
